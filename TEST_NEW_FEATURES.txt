🧪 TEST 2: IMPROVED PAUSE OVERLAY

Steps:
1. Start Quick Play (or any game mode)
2. Move around, shoot some enemies
3. Press ESC key

✅ EXPECTED RESULTS:
- Screen shows:
  ✓ Your frozen game in the background
  ✓ Dark semi-transparent overlay
  ✓ "PAUSED" text in center
  ✓ RESUME and QUIT buttons
- Gameplay is frozen:
  ✓ Your ship is stopped
  ✓ Enemies are stopped
  ✓ Projectiles are stopped
  ✓ Asteroids are stopped

4. Press ESC again (or click RESUME)

✅ EXPECTED RESULTS:
- Pause menu disappears
- Game continues exactly where you left off
- All movement resumes normally

5. Pause again and click QUIT

✅ EXPECTED RESULTS:
- Returns to Main Menu
- Game session ends
