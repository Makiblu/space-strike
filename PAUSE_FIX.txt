🔧 PROBLEM FIXED:
ESC key was not pausing the game

🐛 ROOT CAUSE:
- ESC handler was placed AFTER the state check
- Code was checking "if not PLAYING, return" before ESC could run
- Duplicate keydown listener was conflicting

✅ SOLUTION APPLIED:
- Moved ESC handling to TOP of keydown listener
- ESC now checked BEFORE state validation
- Handles both pause (PLAYING → PAUSED) and resume (PAUSED → PLAYING)
- Removed duplicate listener
- Returns early after ESC to prevent interference

💡 WHAT WAS CHANGED:

BEFORE (broken):
```javascript
window.addEventListener('keydown', (e) => {
    // ...
    if (currentState !== GameState.PLAYING) return; // ← ESC blocked here!
    
    // Pause (never reached when not PLAYING)
    if (e.key === 'escape') {
        pauseGame();
    }
});
```

AFTER (fixed):
```javascript
window.addEventListener('keydown', (e) => {
    // Handle ESC FIRST (before state check)
    if (e.key === 'escape') {
        if (currentState === GameState.PLAYING) {
            pauseGame();
            return;
        } else if (currentState === GameState.PAUSED) {
            resumeGame();
            return;
        }
    }
    
    // Other keys only work during gameplay
    if (currentState !== GameState.PLAYING) return;
    // ...
});
```
